# Simulador FI

Simulador educacional de contabilidade financeira (FI) com telas inspiradas no SAP GUI, para estudar as principais transações: FB50, FB60, FB70, F-53, F-28, FB03, FB08, FBRA, FS00, FK01-03, FD01-03, FS10N, FK10N, FD10N, FBL3N, FBL1N, FBL5N, OB52, F.01, S_ALR_87012277 e SE16N.

**Acesse:** https://guardalucro-cmd.github.io/simulador-fi/

- Empresa fictícia com lançamentos de janeiro a outubro de 2026.
- Guia do aluno em cada tela e trilha com 12 missões.
- Os dados ficam salvos só no seu navegador. Para recomeçar: Sistema → Restaurar base de dados.
- Link direto para uma transação: adicione `#FB03` ao fim do endereço.

Simulador independente, sem vínculo com a SAP SE. SAP e S/4HANA são marcas registradas da SAP SE. Telas, dados e empresa são fictícios e simplificados para estudo.
